# NEXORA – Student Performance Analytics System

**Turning Student Data into Meaningful Insights.**

## About the Project

NEXORA is a Python-based project designed to analyze student academic performance using marks and attendance data. It converts raw student records into useful information, helping users understand overall class performance, identify top performers, and find subjects where students may need improvement.

The main goal of this project is to apply Python programming and data analysis concepts to a practical academic problem.

## Features

- Reads student records from a CSV file.
- Calculates total and average marks for each student.
- Assigns grades and determines pass/fail results.
- Identifies the highest, lowest, and average performance.
- Analyzes performance subject by subject.
- Displays the top-performing students.
- Summarizes class performance and attendance.
- Identifies students who may need academic attention.

## Technologies Used

- **Python** – Core programming and calculation logic.
- **Pandas** – Loading, organizing, and analyzing student data.
- **NumPy** – Numerical and statistical calculations.
- **CSV** – Storing student records.

## Dataset

The dataset contains student details such as:

- Student ID and name
- Department and semester
- Marks in Python, Artificial Intelligence, SQL, Mathematics, and Computer Networks
- Attendance percentage

Total marks, averages, grades, and results are calculated by the program rather than stored in the original dataset.

## How to Run

1. Clone or download this repository.
2. Open the project folder in VS Code.
3. Install the required libraries:

   ```bash
   pip install -r requirements.txt
   ```

4. Run the main program:

   ```bash
   python main.py
   ```

Make sure `students.csv` is available in the location expected by the program.
